# 澄坂市：城市布局 V02

## 定位与统一身份

原创日本通勤卫星城，南侧河流、北侧缓坡、区域铁路。四层空间为河岸低地、生活街区、校园台地、北坡。新站前与旧商店街通过渐变街段相连。共同地标候选为校园西侧旧配水塔“青帽塔”：浅米灰塔身、青绿塔顶，约16米高，基座为维护围栏与小绿地，不设大型旅游广场。

三种身份共同保留；配水塔造型、具体标高和初夏晴天方案仍待审阅。正式城市独立设计，不继承 GameplayLab 或 LifeBlockout。

## 拓扑与道路

```text
神社N ── 北坡U ── 高端住宅R
             │
         青帽塔A      高中G
             │          │
             K ──────── F
             │          │
═══════ 铁路穿越 ═══════ E ═══════
             │          │
住宅北口 ─ S ─ C ─ 过渡街 ─ T ─ 医院
    │         ╱               │
家H─L ─ 公共通学便道           │
    ╲                        商店街
     └──── 住宅南街 ───────── D
                         社区／图书馆
       公园─B1 ═ 河流 ═ B2
             └─未来南岸─┘
```

- 站前连接街：住宅北口—S—C—新旧过渡街—T—医院道路。
- 西通学路：C—K—F；不强制经过站前正门或北坡。
- 东放学路：F—E—T，校门由F接入。
- 住宅南街：L—D；商店街主线D—T，后巷承接员工与送货门。
- 北坡：K—A—U；去高端住宅先沿校园西界外绕到北界外，不穿校园。
- 环路A：L—C—K—F—E—T—D—L；上学和放学不同方向。
- 环路B：L—住宅北口—S—C—过渡街—T—D—L。
- 捷径：L东侧公共通行带—C，少一次绕北口的转折；住宅块中提前留通行带，不穿私人院落。
- 南侧预留两桥与两岸连接；完整河岸不是一期必须深化范围。

## 高差

河岸±0；住宅/旧街+5—6；站前约+8；校园/塔基+12—14；高端住宅约+24；神社后侧约+30米。铁路高于穿越道路，具体结构及净空未验证。

通过河岸下行台阶、桥下空间、站前缓坡、校园挡土墙、顺坡庭院和神社台阶表现，不能只依赖地图文字。参见 [高差示意](../../ArtSource/MapDesign/terrain-section-v02.svg)，这是折线观察带，不是沿同一直线测得的剖面。

## 一期与未来

一期深化校园、家与住宅、商店街及其连接道路；三家重点店为便利店、书店文具店、咖啡店。青帽塔轮廓、铁路、站房与河岸桥梁为城市识别与背景。

医院、神社、高端住宅、完整站内/交通远区、公共图书馆后续深化，但本轮已安排占地、入口、接路、地形与边界。社区中心和交番保留公共服务位置。建筑出现不表示医疗、乘车、购物等系统已经实现。

## 入口、集合点与视线

学校门侧公告板/前庭；住宅巷口；书店侧退界；咖啡店侧雨棚；站前树岛；医院雨棚；神社参道下端；图书馆共同前场，均不堵主要通道。

塔的关键视线从公共便道出口、站前东侧连接街、商店街北口、校门前庭出发。低住宅屋顶之上可露塔顶，站前间隙可见塔身；不要在这些走廊放大招牌或高树。视线在平面上预留，尚未证明真实三维镜头可见。
