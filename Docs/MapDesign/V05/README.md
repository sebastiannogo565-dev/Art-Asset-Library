# 澄坂市 V05 · 校园与山海生活都市

状态：设计提案与一次概念候选，供用户审阅；未认定布局或画风已批准。更新2026-10-08。

V05将校园与学生生活置于中央偏北台地，把铁路移至东部外缘。北山与山麓湖盆接泉渠旧城；主河沿校园东侧进入河口海湾。住宅、校前街、泉渠旧商店街一期同一室外图，校园独立；九概念区不等于九张UE关卡。不会为每对邻区增加纯走路地图。
