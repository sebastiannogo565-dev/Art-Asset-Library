# V08 校园与神社

[规划板01](../../../ArtSource/MapDesign/V08/SL_WORLD_V08_BOARD_01_CAMPUS_SHRINE.png) / [SVG](../../../ArtSource/MapDesign/V08/SL_WORLD_V08_BOARD_01_CAMPUS_SHRINE.svg)。建筑/节点用途详见[索引](building-use-index.md)。

校园360×320m、八原组与入口不改。学校先立台地、城市沿通学路生长为候选历史；C02灰瓦砖基和旧钟/泉院为早期轴，教学/图书/体育沿整治线分期，讲堂与社团共享未来文化。学校生源仍未定。

南门GATE01候选6m开口，门柱/低校牌墙/前庭公告使轮廓可识别；公共路止门外。C01鞋柜/职员保健入口清楚、二层玩家教室保留。C03图书室放学30/60分钟学习，C08体育/储物与操场训练保留，C05文化社团预留。C_library/C_old/C_library_court/C_special规划短有顶连廊，透空柱列和入口断檐，未做旋转镜头遮挡实测。

RT01天台只用C01已有楼梯核，28×21m候选范围，局部8×10m楼梯核/门，连续1.2m候选栏杆与设备边界；候选许可/检修或恶劣天气关闭，不设置开放时段/关系系统。12m屋面高程仅候选，楼层/疏散/结构/安全条件待验证。普通社交仍可在泉院/中庭/走廊端/图书窗边。

POOL01池25×10m候选，50×34m总设施范围，在特别教学翼北侧、操场南侧/社团西侧已有体育空地。C09为12×30m低翼，含更衣12×13、淋浴12×7、设备12×7m以及分隔缓冲；入口、侧设备门与校园路径均连通。池边西6m/东4m、南7m/北17m为规划候选，真实使用净宽/更衣容量/管线尚未验证。未来闭式排水接污水维护，不直接入泉渠。操场仍140×85m，中置100×60m训练分区与缓冲，非完整标准体育场。泳池未挤占既有八翼、不扩校园，只未来空间，无水泳小游戏。

B40建筑不迁：坡脚N05→短分段石阶→12×10m林间平台N06→主鸟居N07→64×17m前庭→社殿；坡向高度差18m候选，不据折线推阶数/真实坡度。林木只留约14m鸟居视窗。W06缓坡+庭院侧路为替代，石阶只步行，自行车最后推行。北侧私有社务院LP09有独立员工/小维护路线，供货方式/净宽未来验证。

夏祭庭院四小临时边摊位置示意、主轴留3m以上候选通路，平日空庭参拜/等人/散步/清掃。怪谈是未定地方传说，神隐/异世界/超自然主线不确认。社殿贴地形、灰瓦温木、非巨大鲜红寺社群。

当前认可人物源图未在库发现，已询问路径；128×128是画布，不是身高。门高2.2–2.4m/家具与扶手以后结合认可图局部检验，未报告人物比例通过。
