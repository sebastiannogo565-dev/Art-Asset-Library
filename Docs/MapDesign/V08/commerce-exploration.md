# V08 双商业与少量探索

[规划板02](../../../ArtSource/MapDesign/V08/SL_WORLD_V08_BOARD_02_COMMERCE_STATION.png) / [SVG](../../../ArtSource/MapDesign/V08/SL_WORLD_V08_BOARD_02_COMMERCE_STATION.svg)；[规划板04](../../../ArtSource/MapDesign/V08/SL_WORLD_V08_BOARD_04_COAST_LAKE_EXPLORATION.png) / [SVG](../../../ArtSource/MapDesign/V08/SL_WORLD_V08_BOARD_04_COAST_LAKE_EXPLORATION.svg)。

旧街/校前是学生便宜熟悉放学中心：B02翻新灰绿便利门带；B03温木窄文具门面，B04工坊砖基/蓝灰坡顶咖啡，B05旧手艺瓦木，B06暖灰小食/B07灰绿运动门面。两段墙上短棚避免铺满道路；朋友凹口与顾客门、员工后门/送货后巷分开。楼上住家/邮箱/晒物退界、家常食物日用品与维修缝补保持全年需求。咖啡为普通帮工，不开发经营。

N08/N09小食/书店等候，N10只一处16×20m街角小公园与售饮机候选，非每路口复制。雨棚1.5m出挑候选不是人物/镜头遮挡通过；主要入口需开树冠/断檐。成年消费、医护家庭与通勤采购保留。

东商/站前以换乘和较久周末消费为主：FC_STATION疏荫两块、公交棚到站门/街道连续，车回转在旁侧虚线预留。U25家庭餐厅约33×24m、U26小电玩约20×20m复用B32内部，仍用现有顾客门与员工后门，门厅/防声/具体摆设未来；新餐厅/电玩不生成独立楼体或小游戏。P03旧门面→翻新底商→公寓办公→绿地退界至P04站前，不铺满购物长廊、不迁旧街。

南海湾居民街入口N14有6×3m遮阴短棚、售饮/小维护候选，座位在中段与N15沙滩停留；补货止陆上入口。湿地、沙滩、岩岸各自景观，部分岸段继续安静，无全线精品店。

B42白岬小灯塔：已有东南岩岸陆上位置，6×6m基座、8m低白塔/灰青罩候选，旧小船归湾导向灯和今日岸务维护解释。N16观景先于塔门，塔内维护授权，不压校园/青帽塔。法定航标、灯向/潮汐/岸体真实工程未知；因无港池/水域遮护用途，不采用防波堤或大港口。与蓝帽配水塔（生活定位）和校钟（学习历史）分工。

B43湖林旧水务巡检小屋：6×8m暗木青灰低坡，高3m候选，西湖林岸既有巡检环路接约60m窄支路、旧水务刻记与清理工具痕迹；仍维护良好，不破败。门前到达可选探索，室内锁闭维护，低可见不必全城显眼。探索优先C02/工坊/配水历史，不同时加废校隧道遗迹。电车隧道只后续替代、不画不改铁路，奇幻真假继续待定。
