# 昼夜与小渔务航路

神社坡脚/分岔/转折平台/入口低位暖光，踏面边缘柔亮，森林暗，主鸟居局部受光；平日少灯，祭典可撤提灯另候选。便利店较亮节点；书咖柔和内透；站出口/候车/接续路可读；住宅少窗、湖林自然岸暗。关闭以门/卷帘/标识表达，不规定营业时段或光照工程值。
