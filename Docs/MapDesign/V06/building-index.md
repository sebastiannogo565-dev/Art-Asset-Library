## 公共前场、私人边界及校园

医院东公共门/西职工后勤；公共馆南公共入口/北职工入口；社区中心公共门与西后勤边；站房步行前场与西员工门分开；商业前场接公交，东后场接送货。5处公共前场在front_courts图层，保持候车通道。

校园主门、东授权门、鞋柜至主教学走廊、泉院后门与连廊相连；主教学—图书—体育使用既有直接网络。八翼不扩占地。旧校钟、泉院、中庭/午休、食堂边缘、文化扩展与安静角落保持三级使用：高频、可选停留、未来剧情。校内图书室30/60分钟学习只作为空间用途，体育保留；公共图书馆独立、晚间未来。外部居民不借校园通行。
