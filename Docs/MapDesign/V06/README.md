## 相对V05的深化

不重排城市。复用底商、楼上住家、配室与现有后场，增加24个用途单元、15项就业场所说明、13项重点店客源说明、53处公共/授权接入记录、5处公共前场和8个后勤接驳点。用途单元不是新增建筑ID，也不表示相关玩法已实现。

西区补普通独栋与青年租住层次、食品药店/托幼照护；东区从高楼身份转为小企业、专业服务、文化和职工租住。仅3个背景体量修改候选层数：BG_W_03 3→2层，BG_E_03 10→7层，BG_E_05 11→6层。没有增加重要楼栋或继续扩大校园。

旧工坊、泉渠、桥基、井台、校钟和青帽塔今天仍被使用。旧商店街表现顾客门、员工门、楼上住家、送货与取件，不全部依赖放学客源。饮水、清洁雨水/泉水和污水分流；处理和大配送在图外。

## 制作与停止点

本轮没有制作3D模型、UV、环境纹理成品、游戏NPC、车辆、完整室内或UE资产。建筑模块仍以矩形体块、不同退界、分翼与公共/私人门组织为方向。62个建筑摆放体量不等于62个独特模型；未来模型清单在局部样板通过后统计。

下一步先审阅城市用途、路径绕行、容量假设和唯一候选画风。通过后另行安排“玩家家巷口—校前街—校门”HD2D样板。当前停止，不追加生图或自动建模。
