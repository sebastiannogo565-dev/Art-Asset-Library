# V06 生活经济关系

## 工作假设与收入来源

澄坂市是与邻近大城市相连、拥有历史名校、区域医疗和山海环境的生活小城。学校和旅游各自只是一部分收入。

1. 居民通过东外缘铁路到邻近都市工作；站前便餐、公交和住宅归家道路有全年需求。
2. 教育、医疗、图书/社区、照护、清洁与设施维护提供本地工作。
3. 东区分租办公室、小企业、专业服务和文化机构与周边城市协作；不是大型总部集群。
4. 本地家庭、租客和职工支撑食品、家常餐食、文具、洗衣、手艺和维修。
5. 山湖/海湾休闲访客增加周末需求；居民日常和成人消费仍是基础，不沿海岸铺满精品店。

学校先立于泉源附近台地，通学道路与工坊贸易路推动城镇发展，是候选历史解释。生源范围仍待定，不能拿图中住宅数量解释名校规模。小学/初中暂指向R03西北图外公共教育片区，不新增两套完整校园，位置与安全接驳待定。

## 绕路与服务缺口

二维闭合不能单独证明日常便利。西区医护家庭从BG_W_01去B20西后门、再去BG_W_02采购，现有外围公共路需绕公寓组团；没有穿私院补虚假捷径。此处在后续西区局部底稿应评估公共短巷或食品服务入口微调。当前不在冻结生图底稿之后偷改道路，绕行未认定通过。

北坡退休家庭需要未来支线与无台阶缓坡；支线未实现，真实坡度和舒适性未验证。东区青年帮工跨区也可依赖未来公交，不能据DU长度设交通时间。小学初中图外安全路、托幼照护容量、医护后勤隔离、食品配送净宽均待验证。其余需求缺口见容量表。
