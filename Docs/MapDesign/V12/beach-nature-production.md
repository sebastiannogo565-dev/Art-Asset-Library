# 海滨三体验与自然候选

入口活动段：原N14/CS01短棚、居民路/原V08_BEACH_ENTRY，车止陆侧[1450,900]，手推到柜，6m²洗脚收水候选。安静段：西侧空沙、后缘3m步道、稀疏坐面，回入口或西住宅。自然段：向东草岸/岩缘陆侧连河口，芦苇潮沟耐盐植被少物件。

原连续沙滩只到约x1700，河口约x3000。三段是连续海岸体验，不能新增长沙滩把中间草岩岸都变浴场，这是保持正式岸形的取舍。返回方向清楚，海滨绕行可选，不延长家校。

初夏日常2伞少人，无球网或泛滥救生塔；旺季候选6伞、一16×8m可拆网、一3×3m救生架、小轻摊；淡季撤柜，超容量图外租仓，垃圾原LP08，维护手推不挡路。泳区水深/水质/救生/防灾未验。船艇只B44作业岸，不放普通泳区。

B44继承7000m²L地块、432m²单楼、2100m²原院及八分区，东顾客/观船退界、西员工、南院卸货清洁回转与自然缓冲；灯塔走原陆路不穿院。箱筐网具/卸货窗/保冷表达生产身份，不封自然河口建巨港。靠泊未核可改邻区供货。

湖：入口木牌→途中树冠开口预见湖景/刻记→早返或B43门外→原路返，栏仅必要落差。B43授权锁门，不变旅舍。单432m²营地2–3帐篷沿原环路分口，撤收垃圾管理/厕所距离/树根空地待核，其他岸安静。正常窄湖口石坎/水位刻记与雨时小沟分开，分水林坡/独立源流保持；概念42/41.8m水位未实测。

神社：一主鸟居、灰阶/平台、小庭社殿视线，缓坡与供货原路，初夏绿荫，不整山红粉。东北农地4顺坡绿田，公众西边木牌/农戶私维护路分开；1温室/1可移农具棚内含同地块，初夏幼苗青菜不是金色收获。BG_N_057供货家庭解释/土地灌溉许可待审，无风车理由，不做采集农业。
