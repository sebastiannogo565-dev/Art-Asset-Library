# 统一多视图参考图任务要求

本文件为后续参考准备的任务合同。本轮不执行生图或制作设计板。

## 先核空间

先建立同一份尺寸表和可编辑平面/立面约束：功能、边界、底轴心/朝向、各层标高、入口和后门、室内与外壳对应、屋顶脊线/坡向。标明正式规划、灰盒实证、设计候选与待核；未知尺寸不从概念图推为施工值。

## 一套建筑、一套视图

|视图|必须表达|
|---|---|
|总平面/各层简化平面|米制或厘米、入口编号、主要房间、楼梯、通路、外廓和后勤/私人边界；可进入空间明确|
|前/后/左/右立面及屋顶平面|同一门窗编号、层数、檐高/脊高、屋顶坡向、檐沟与排水方向；后墙不复制正门|
|相反两向斜俯视|同体块/同门窗/同材色/同光照；约30°俯角、一向正侧、一向背侧，不镜像或自由重新排列|
|必要剖面/拆分图|可进入建筑屋顶、外墙/外壳、楼层/室内分离及连接位置；首层入口、楼梯净空与楼板关系|
|人物尺度与入口局部|原认可人物约1.8m可见高，只读；门洞/家具/通路/窗台对照，标实际观察条件|

可将这些组成1套SVG/PNG设计板，而不是强制每件部品独立出图。若AI辅助造型，先统一底稿约束再生成参考；独立生成的前后图不自然证明几何一致，偏差须列出，由编辑底稿统一。AI文字不作为精确标牌。

## 风格和交付

写实建筑结构＋克制像素纹理＋自然昼光。初夏绿叶，米白/暖灰/暖木/青灰协调；材质平铺尺度与人物画布分开，不能把照片像素化当设计完成。窗内/外墙、屋顶/背面都成立，主要入口不被树冠或连续大檐遮死。

- 可编辑SVG/原生PNG，多视图建议3200×2400或足够读图的原生规格；尺寸按设计板用途，记录实际规格。
- 同步尺寸/布局JSON、规格Markdown、参考来源/采用表、候选与未核项。
- 关键尺寸至少包括：占地/外廓、总高/层数/层高、檐脊、入口净宽高、窗台、楼梯/楼板与外墙厚度、院界/地面接口。无依据项先核或以明确候选提出，不偷偷冻结。
- 若调用生成，另保存原下载、提示词、参考、工具/模型和真实尺寸，不以插值当原生。当前没有调用任何生成。
- 参考通过后建模聊天按同一建筑包交Blend、FBX、UV、临时纹理、自然光整体两向、可进入空间检查及manifest/review。无需为组内每个门窗/管件另等用户批准。

参考、网格交付与实际游戏验收分别记录。本规范不要求工程开发、运行屋顶隐藏代码或UE接入。
