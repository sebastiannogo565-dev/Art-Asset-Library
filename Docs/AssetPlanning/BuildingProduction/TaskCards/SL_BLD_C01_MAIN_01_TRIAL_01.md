## 制作顺序与深度（一栋内完成）

1. **先验证高频净区**：在试作源中复建玩家班、入口/鞋柜、典型梯并核下表；这是整栋前段，不独立发布资产卡。局部调整桌椅/柜列/五金属于组内处理，固定基准变更才回报整体取舍。
2. 全栋外壳、四立面、浅坡/核心/连接屋面、全部门窗/遮阳和三入口；三层楼板、主廊、S1/S2/S3与半平台、电梯井空间及庭/露台围护。电梯只留空间，不制作运行系统。
3. 玩家30席教室、主要鞋柜和入口、主要公共停留点有必要陈设及可读细节。其余23间普通班保房间/门窗与必要重复家具示意，管理/辅助室保壳体和用途所需低深度陈设，不全楼精装。
4. 整理适合后续使用的网格、UV与共享临时材质，实际自然光A/B/屋顶/内部预览，导出FBX并回导核单位/方向/分组；完成整栋回件停审。

不要直接把参考中6642盒/面指示及展示副本当最终拓扑。可复用参考尺寸或局部网格，但清理重复共面/内部重叠、未归属面与展示副本；输出真实源对象/实例、顶点三角/材质/贴图统计，源模型数与摆放次数分开，不凭参考指示数冻结面数预算。

## 分组、UV、临时纹理与预览

- `ROOF / EXTERIOR / SLAB_F01–03 / INTERIOR_F01–03 / STAIR_CORE_S1–S3`，标需要独立隐藏的外墙、分隔墙和顶面；屋顶/楼层隐藏不带走应保留楼梯、平台和围护。外墙内外一套归属，庭及梯孔跨板与下层顶面贯通。共原点/标高，部件不各自归零。
- 全栋可见外观、主廊/楼梯/玩家班/鞋柜和必要陈设有实际可用UV；背景房可共享/平铺，复用重叠与独占区明确，不能整楼都称唯一UV。窗/墙/屋顶/家具使用共享材质，避免每扇窗一材质。材质槽和导出可追溯。
- 临时基础色、粗糙度和必要遮罩，写实际像素尺寸/格式/UV或平铺密度；近处64px/m为测试起点，可同1m面比较32px/m，最终建议有同镜头证据，不把旧SVG小样算完成。贴图不固定太阳阴影，不把环境纹理强制128²。玻璃检查透明/暗部与入口可读性，不靠自发光掩盖。
- 整体A西南/B东北、约30°俯角同初夏日光；屋顶/四面可读，另交分层拆卸/庭梯洞、玩家班两椅态、鞋柜及入口材色、原人物比例检查。主检查用约30°、必要25°/40°辅助，镜头条件实际记录，不宣称等于UE镜头结果。原人物展示层可隐藏，原PNG字节不改。
