# 完整建筑/建筑组任务卡模板

状态应注明推荐草案、参考准备、待审、用户已转交等。本窗口只规划与审阅，建模聊天在用户转交后执行；本模板不自动授权批量生产。

1. **资产ID、地图建筑ID、用途及任务边界**：完整建筑/可独立使用组，日常功能、可进入范围、公众/私有/后勤入口。
2. **参考文件**：正式布局、灰盒记录、认可人物、风格参考及实际读取部位；工程只读。
3. **尺寸约束**：占地、标高、层数、入口、各层关系、轴心/朝向、边界；每项区分已知/候选/待核，冲突写差异。
4. **复用与统计**：建筑包/独特网格/组件/摆放分别计；已接受源的ID/路径保持，门窗檐管为组内拆分；独立复用/交互/重大取舍例外才另列。
5. **统一多视图参考任务**：同尺寸平面、四立面、屋顶、正背两向、必要剖面、人物比例，风格及源文件/真实尺寸明确，引用[multi-view-reference](multi-view-reference.md)。
6. **完整制作要求**：建模聊天负责内部拆分、模型/UV/临时纹理/整体预览；可进入建筑明确屋顶、外壳/墙体、各层室内分离及接口，不能靠单面墙或永久无顶蒙混交付。
7. **交付文件**：参考阶段SVG/PNG/JSON/规格，制作阶段Blend/FBX/Textures/Previews/manifest/review；已有源不覆盖，UV/分辨率/密度/材质槽/实际数量记录。
8. **验收与停止点**：同源多视图、尺寸/入口/屋顶/室内一致、原人物与写实像素自然光协调、来源保护、正常Git/LFS。整组回件审阅，不逐窗逐管审批，不自动UE或下一栋。

可进入建筑源建议集合ROOF、EXTERIOR、INTERIOR_F01/F02等；分离可用对象/集合，不要求每面墙单卡。实际导出分组/共享定位/去重几何和接口由该建筑卡指定，不擅自运行地图隐藏或切换系统。
