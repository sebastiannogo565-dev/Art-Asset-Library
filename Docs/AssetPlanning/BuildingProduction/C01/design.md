# 建筑定位、体量与功能方案

一栋现代日本高中主教学楼：真实层高与结构尺度、克制像素表面、自然昼光。先进感来自光、通路和学生能使用的空间，不靠通体玻璃幕墙、巨大中庭、屏幕或新钟塔。旧校钟与分期历史继续由C02承担。

正式约束：V13 C01控制150×28m、三层、旋转0°。SW原点world(2190.909091,1969.181818)m；+X东/+Y北；南门(25,0)、北门(90,28)、东口(150,14)保持。原墙体长方形是控制/历史基线，本轮在范围内研究退进；不直接更改权威footprint。

推荐分段 **52m西教学—12m西连接—30m学习交流核心—12m东连接—44m东教学**。54/12/22/12/50的原讨论组合会让核心止于x88，而北门在x90；新核心64–94容纳北门，同时玩家教室原x45仍在西教学段。入口不挪到交流核心中央。

教学段主要深18m、两连接深14m，核心深28m；鞋柜前厅与楼梯前凸仍在控制范围，北侧退出形成绿带/窗景，南侧实体与短檐交替。所有进退都有教室、辅助空间或通路用途，不随机扭楼。实际覆盖3016㎡，不是满铺4200㎡。近门米白墙/暖木公告与鞋柜，教学面青灰浅坡金属顶，连接浅金属檐，核心框架内透光/局部平顶采光；整体不采用镜面幕墙。

三层各8班，西4/东4。F01一年级、鞋柜、保健/咨询、职员与管理；F02二年级/玩家班、学生会/媒务、年级事务和交流厅；F03三年级、升学咨询、安静讨论及60㎡受控小露台候选。卫生间分东西，3座楼梯分西/核心/东、1处电梯预留；维护/储藏位置有对应，不穿教室。班级间保8.6m研究模数，净教室8.4×9m，结构跨度及柱网细化未验。

交流核心用12×9=108㎡小采光庭，三层通高，F02/F03按孔位扣面积；底层边缘坐面、短展示与等人，中央走线保持。周围真实年级交流/观察廊与讨论步台支撑课间、午休、自然偶遇；不是独立图书馆或礼堂。玻璃只集中连接/核心部分，教学段保持实体窗墙和遮阳。

图书室学习继续C03，实验/艺术C04，文化社团C05，讲堂校史C06，食堂C07，体育C08/FIELD；不在C01复制全部功能。三层60㎡露台不是原RT01屋顶588㎡的自动替代，原屋面访问仍候选；退进方案会使RT01部分越出新屋面，须另行核边界，当前不默默迁移。

教室候选30–36席：75.6㎡净矩形中研究6列×6排，桌0.65×0.45m/高0.72m、椅座0.43m，教学前场与后场保留；30席可去掉一排。门1.6×2.6、走廊3.6、梯跑2.2、层高4/净3.45均为研究参数。每班辅助门/板书/窗台与座位细排、疏散/真实人体行为不在本轮通过。

24班候选并不挤，反而面积较宽裕：净教室共1814.4㎡，三层可分配水平面积8599.62㎡，余量明确列为辅助/公共/交通/结构待细化，不编造满楼功能或新增NPC。首期精作入口、主廊、玩家班与关键梯/图书体育接口，其余课堂完整壳体少陈设即可。若希望更紧凑，可在审阅后缩辅助/公共深度，不挪三入口或硬加班数来填面积。
