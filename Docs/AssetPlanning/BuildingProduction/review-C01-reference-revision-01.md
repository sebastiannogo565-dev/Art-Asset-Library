## 保留到整栋试作的验证项

1. 先用真实试作网格、认可人物原图及独立胶囊/操作包络核指定入座离席、椅后拉、门口转向；不缩人物、不把细缝列成通道。不要求本轮规划凭参考图宣称导航通过。
2. 900格保持名义目标，0.30m单面深**不作为已接受最终柜深**。试作先画/做典型格有效腔深、薄板/隔板/门轨，比较明确尺寸的鞋代理，复核实际站位和柜前过路；若不够，在整栋组内优化柜列/五金候选，不自动减少格数或扩占地。
3. 一面操作和交叉让行仅是当前参考检查条件，不是新NPC规则或已经验证的运营方法。试作应把双面操作失败及队列封路情形如实展示；若900格与通行无法兼顾，提交带数量/占地差额的整体取舍，不以“错时”文字掩盖矛盾。
4. 三条楼梯、楼板/下层顶面开洞、屋顶/外壳/分层隐藏组合、F02实际标高、门窗家具与约30°镜头纳入同一整栋任务。最终UV、像素密度和自然光需真实模型验证；本次无SchoolLife写入，不执行导航代码或UE。

这些是同一试作任务的前段和回件验收，不另拆审批卡。若前段暴露基准冲突，记录未通过及代价，停止受影响部分的精作；外观/未受影响部分可继续。只有控制范围、主入口、班数/席数、庭/露台或保护输入需更改时回规划判断，不逐门窗家具请求批准。
