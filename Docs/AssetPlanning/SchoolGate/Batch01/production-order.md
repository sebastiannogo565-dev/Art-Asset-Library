优先顺序并不意味着地面要重建：第0步先沿用已建地形道路作为尺寸底盘，第一份**新单体**才是门柱，不能先批量造道具填图。

统一风格要求：写实建筑结构（可信支承/落地/接缝，不以纯矩形贴字冒充完成）＋克制像素纹理（不是照片像素滤镜）＋自然昼间光照。米白暖灰/青灰只作V13校园材料关系参考，柱材种、压顶轮廓、纹理密度和分辨率均留单体设计审阅，不在本轮画出来。结构真实与Q版人物可以共存，128×128限制仅角色。四面/顶面成立、主通道/角色不被大梁或树棚遮死；本轮没有旋转镜头实测。

停止线：交资产表与门柱文字卡后停审。用户批准清单并转交卡，接续聊天才按其明确授权范围开始。任何改校园面积、改道路高差、加整面校墙或扩大入口，都先作为差异回报，不用成品概念图倒推施工。
