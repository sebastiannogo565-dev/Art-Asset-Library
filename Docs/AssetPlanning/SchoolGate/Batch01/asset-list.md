# 校门入口第一批资产清单

2026-10-13。仅规划，所有“新源数量”都是后续制作预算，本轮新增模型/材质/纹理/图片=0。ID缩写GE＝Gate Entrance；各表依赖省略SL_GE_前缀，仍指同ID。本表没有批量生产授权。

范围：保留现8×5m入口平台及双柱，处理其接触的南通学坡/北校内路和必要露底边缘。未冻结扩展ROI，不把整条校前街、校园、PS01所有物件或19.19km²地形纳入本批。

P0＝先核并沿用的基础；P1＝首批必需计划；P2＝有现场/施工证据才补；P3＝后续候选，默认首批不放。尺寸证据见[尺寸与复用](dimensions-and-reuse.md)，顺序见[制作顺序](production-order.md)，首张[门柱任务卡](TaskCards/SL_GE_GATE_PIER_01.md)。未知项写待核，而不是零尺寸。
