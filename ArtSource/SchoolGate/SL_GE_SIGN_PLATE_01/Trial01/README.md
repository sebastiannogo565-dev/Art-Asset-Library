## 装配、锁定、拆卸

装配候选为柱侧U座＋牌侧倒U挂钩＋右侧防抬滑舌。先装垫和柱侧两座（四轴仍只是位置参照，柱原源没有孔），牌背先装挂钩/导座，滑舌右退1cm解锁。牌侧抬1.8cm、向南外移0.6cm，对齐后向+Y靠柱、沿−Z落座。东侧折边服务口有明确工具通道，钩头进入舌片Y贯穿钩孔，从+X侧推舌−X 1cm至止位，舌顶抵下座底面限制抬升。最后的防侧向自退拟采用弹片/定位槽；其弹性、结构和可靠性尚未验证，当前网格不把细碎弹片/螺丝当作已完成紧固。

拆卸：同侧先解除止退、钩拉舌+X 1cm，再抬牌1.8、向−Y外移0.6取下。柱侧座/垫留柱，拆座时才再次露出四轴。临时上抬最高宿主Z183.8仍在可用面上界190内；外移是服务扫掠，成品/安装包络不增加。两个真实钩孔/工具轴线的零半径射线通过；有限工具截面、手部操作、工艺公差与承载不因此通过。

相对Design：把两个实心支座布置包络细化为分离的18cm柱侧U座/16cm倒U钩，新增导座/滑舌/双止位、末止位工具通道、滑舌功能钩孔及折边服务口。外形/前皮/总突出/高度/宿主均保持。钩孔只属于校牌功能件，不是宿主锚固孔；试作尺寸不冻结真实紧固规格。

东侧口X11.8..12、Y−1.8..−1、Z−31.8..−30.9cm；导座工具通道Y−1.5..−1.2。滑舌锁位X8.2..10.6，解锁X9.2..11.6，顶Z−31.2抵下座底；锁位X重叠0.8cm，释放后水平净隙0.2cm，挂接Y候选净隙0.05cm。原30×100不是牌尺寸，原Design不覆盖。
